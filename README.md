# Copyright Test

A standalone, browser-only YouTube Studio-inspired copyright workflow simulator.

## Run it
Enable GitHub Pages for this repository:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Open the published Pages URL after deployment completes.

## Included
- Studio-inspired navigation and Content detection page
- Matches, Removal requests, Messages and Archived tabs
- Multi-video demo removal request form
- Scheduled and standard request options
- Prevent-copies toggle
- Simulated review outcomes after a random 1–5 minutes
- Local browser persistence using localStorage

## Important
This is an independent simulation, not an official YouTube product. It does not contact YouTube, submit legal notices, find actual copyright matches, remove videos, or affect accounts. Requests are stored only in the current browser. Use fictional test information only; do not enter personal contact details or submit real claims through this demo.

No build tools, Node.js, backend, API keys, or environment variables are required.
